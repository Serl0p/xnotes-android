# xNotes plugins

Each subfolder contains plugin source. ZIP the files at its root (not the enclosing directory), rename to `.xplugin`, and import via the Plugins tab. Quick Tool Menu 1.1 and Advanced Stylus Controls 1.1 require API 5. Legacy Annotation Exporter and Obsidian Companion are superseded by Universal Exporter. For old versions see historical branches. API 4 and earlier packages still work on API 5.

Quick Tool Menu: enable, map to a stylus gesture, then hover and click; set favorites and limit (3–8) in Plugins. Advanced Stylus Controls: configure timings in Plugins, then map actions in Preferences > Input. Signing unchanged.
